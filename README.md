# victorialayne.photos

Website for Victoria Layne Photos — portrait, couples, wedding & event photography in Wise County, TX.

Static HTML/CSS/JS, hosted on GitHub Pages, domain via Porkbun.

## Structure

- `index.html` — homepage
- `css/style.css` — design system (warm cream / dusty blue / sage — see project kb, Brand Direction)
- `js/main.js` — minimal JS (mobile nav)
- `img/` — optimized web images (sourced from the project's `photos/web-ready/`)

## Deploy

Push to `main` → GitHub Pages publishes automatically.
